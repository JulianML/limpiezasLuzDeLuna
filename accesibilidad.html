Accesibilidad

ADRIÁN FRANCISCO ROMERO FERNÁNDEZ tiene el compromiso de adaptar los contenidos de la web https://limpiezasluzdeluna.es/ para que todas las personas, independientemente de tener una discapacidad, de la edad, o de acceder a la Web desde tecnologías poco convencionales, puedan tener un acceso universal a todos los contenidos de este sitio Web, sin encontrar dificultades de acceso.

Para ello, los criterios de accesibilidad implican el cumplimiento de las Pautas de Accesibilidad al Contenido en la Web 1.0, en su nivel doble-A, establecidas por el W3C (Consorcio de la World Wide Web), asociación internacional formada por diferentes organizaciones, públicas y privadas, que trabajan conjuntamente para desarrollar estándares con el fin de favorecer y difundir las buenas prácticas en desarrollo Web.

Asimismo está adoptando la normativa vigente en España al respecto: Norma UNE 139803:2004 «Aplicaciones informáticas para personas con discapacidad: Requisitos de accesibilidad para contenidos en la Web».

Situación de cumplimiento

Este sitio web es parcialmente conforme con el Real Decreto 1112/2018, de 7 de septiembre, sobre la accesibilidad de los sitios web y aplicaciones para dispositivos móviles del sector público, debido a la falta de conformidad de los aspectos que se indican a continuación.

Contenido no accesible

A pesar de los esfuerzos por mantener el sitio web accesible, es posible que se encuentren algunas dificultades de acceso en determinados momentos por motivos técnicos o de mantenimiento. No obstante, se realizan revisiones periódicas para detectar y corregir posibles incidencias de accesibilidad.

El contenido de este sitio web está diseñado para ser accesible y se revisa continuamente. No obstante, y a pesar de los esfuerzos por mejorar la accesibilidad, pueden existir contenidos que aún no sean totalmente accesibles, como por ejemplo:

  • Fallos puntuales de edición en alguna página web.
  • La carga desproporcionada no se aplica en este sitio web.
  • Contenido fuera del ámbito de la legislación aplicable, como por ejemplo archivos en formato PDF, contenido de terceros que no esté directamente bajo el control de este sitio web.

Contenido opcional

La versión visible de esta política de accesibilidad de este sitio web es la del 06 de febrero de 2025. Desde entonces, se realizan revisiones diarias del contenido del sitio web para garantizar la accesibilidad del mismo.

La presente declaración de accesibilidad se aplica al sitio web https://limpiezasluzdeluna.es/

El sitio web aplica los criterios de accesibilidad de la Norma UNE-EN 301549:2019, que regula los requisitos de accesibilidad para productos y servicios TIC.

Entre las medidas adoptadas para mejorar la accesibilidad se encuentran:

  • Uso de texto alternativo en las imágenes.
  • Enlaces con descripciones claras y concisas.
  • Estructura del sitio web basada en XHTML 1.0 y CSS 3.0, con un código válido según los estándares del W3C.
  • Diseño adaptable (responsive) que permite una correcta visualización en diferentes dispositivos y tamaños de pantalla.
  • Cumplimiento de las Pautas de Accesibilidad al Contenido en la Web (WCAG) en su nivel AA.
  • Permite cambiar el tamaño del texto y los colores de la página a través de las opciones de configuración del navegador.
