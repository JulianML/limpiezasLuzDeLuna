Accessibilité

ADRIÁN FRANCISCO ROMERO FERNÁNDEZ s'engage à adapter le contenu du site web https://limpiezasluzdeluna.es/ afin que toute personne, quel que soit son handicap, son âge ou le fait qu'elle accède au Web depuis des technologies peu conventionnelles, puisse avoir un accès universel à tous les contenus de ce site Web, sans rencontrer de difficultés d'accès.

Pour ce faire, les critères d'accessibilité impliquent le respect des Règles pour l'accessibilité des contenus Web 1.0, au niveau double-A, établies par le W3C (World Wide Web Consortium), association internationale composée de différentes organisations, publiques et privées, qui travaillent ensemble au développement de normes afin de favoriser et diffuser les bonnes pratiques en développement Web.

Nous adoptons également la réglementation espagnole en vigueur à ce sujet : Norme UNE 139803:2004 « Applications informatiques pour les personnes handicapées : exigences d'accessibilité pour les contenus Web ».

Situation de conformité

Ce site web est partiellement conforme au Décret royal espagnol 1112/2018, du 7 septembre, relatif à l'accessibilité des sites web et applications pour dispositifs mobiles du secteur public, en raison du manque de conformité des aspects indiqués ci-dessous.

Contenu non accessible

Malgré les efforts pour maintenir le site web accessible, il est possible que l'on rencontre quelques difficultés d'accès à certains moments pour des raisons techniques ou de maintenance. Cependant, des révisions périodiques sont effectuées pour détecter et corriger d'éventuels problèmes d'accessibilité.

Le contenu de ce site web est conçu pour être accessible et est révisé en permanence. Cependant, et malgré les efforts pour améliorer l'accessibilité, il peut exister des contenus qui ne sont pas encore totalement accessibles, comme par exemple :

  • Erreurs ponctuelles d'édition sur certaines pages web.
  • La charge disproportionnée ne s'applique pas sur ce site web.
  • Contenu hors du champ de la législation applicable, comme par exemple les fichiers au format PDF, le contenu de tiers qui n'est pas directement sous le contrôle de ce site web.

Contenu optionnel

La version visible de cette politique d'accessibilité de ce site web est celle du 6 février 2025. Depuis lors, des révisions quotidiennes du contenu du site web sont effectuées pour garantir son accessibilité.

La présente déclaration d'accessibilité s'applique au site web https://limpiezasluzdeluna.es/

Le site web applique les critères d'accessibilité de la norme UNE-EN 301549:2019, qui régule les exigences d'accessibilité pour les produits et services TIC.

Parmi les mesures adoptées pour améliorer l'accessibilité figurent :

  • Utilisation de texte alternatif sur les images.
  • Liens avec des descriptions claires et concises.
  • Structure du site web basée sur XHTML 1.0 et CSS 3.0, avec un code valide selon les normes du W3C.
  • Design adaptable (responsive) qui permet un affichage correct sur différents appareils et tailles d'écran.
  • Conformité aux Règles pour l'accessibilité des contenus Web (WCAG) au niveau AA.
  • Permet de modifier la taille du texte et les couleurs de la page via les options de configuration du navigateur.
